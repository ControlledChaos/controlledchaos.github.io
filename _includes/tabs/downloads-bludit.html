The following products I have built for use with the Bludit content management system, which static files to store data rather than a traditional database system as used by WordPress.

Configure 8 Suite

The Configure & suite of products, one theme and several plugins, were designed to work together. But the plugins can be used without the theme.

Each product is available for individual download or you can download all in a ZIP bundle.

More info at https://ccdzine.com/projects/configure-8/
