I don't have anything built specifically for ClassicPress but my WordPress products are built with ClassicPress in mind and they will all work with either content management system. In fact, the plugin & theme boilerplates are designed without much provision for the WordPress block editor, although they are compatible.

Site Core Plugin

This plugin I built to save myself time writing plugins that are specific to client websites. It is compatible with Advanced Custom Fields.

Included are several base classes for adding features for your website project. Simply extend the relevant class. Sample, starter files for each are provided to copy, rename, and develop for your needs.

  • Register post types
  • Register taxonomies
  • Register widget types
  • Register shortcodes
  • Admin pages
  • Admin subpages
  • Title filters
  • Content filters
  • ACF options pages
  • ACF options subpages

Front Core Theme

This theme was built to be compatible with the Site Core plugin and can be developed into your own frontend framework. It is also ready for use with Advanced Custom Fields.

Out of the bow, the Front Core theme has a rather ordinary, simple look & layout. But that is because it is a boilerplate, a starter template for building your own framework. The template system put in place, combined with its companion plugin, makes it easy to start a fully custom website.
