I don't have anything built specifically for ClassicPress but my WordPress products are built with ClassicPress in mind and they will all work with either content management system.

Site Core Plugin

This plugin I built to save myself time writing plugins that are specific to client websites. It is compatible with Advanced Custom Fields.

Included are several base classes for adding features for your website project. Simply extend the relevant class. Sample, starter files for each are provided to copy, rename, and develop for your needs.

  • Register post types
  • Register taxonomies
  • Register widget types
  • Register shortcodes
  • Admin pages
  • Admin subpages
  • Title filters
  • Content filters
  • ACF options pages
  • ACF options subpages

https://github.com/CCDzine-Builds/sitecore

Site More Plugin

This was built to extend the Site Core plugin so that you can develop Site Core into your your own core plugin used for all of your websites then use Site More for site-specific features.
