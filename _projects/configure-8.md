The Configure 8 Suite consists of plugins and themes that I developed for Bludit content management system. Each component is available separately and can be found on the [Downloads](https://ccdzine.com/downloads) page.

In September 2024 I saw Bludit in a list of "static" content management systems (not requiring a database). So I installed it and started poking around the code. I found it to be intriguing but the themes and plugins that come with Bludit are, to put it politely, are not impressive.

So I started to build my own theme. I had no use for a Bludit website but I find it to be enjoyable and challenging to dig into new code. What started as a simple theme has blossomed into a complete set of Bludit products.

## The Themes

The name of Configure 8 came as the theme options began to grow. I was on the website of a car manufacturer and they, as do many, have a "configurator" to spec a car to your tastes. I thought that Configurate would be a good name then I changed it to Configure 8 because the 8 is like a vertical infinity symbol, a reference to the many combination of theme options.

Bludit allows themes to be applied to administration pages (the backend or admin). So I built one to complement the Configure 8 theme. The color schemes and font schemes in the options are applied to the admin theme as well as to the public theme.

## The Plugins

The Configure 8 theme requires a companion plugin for the theme options form; this is the Bludit way. The theme can be used without the plugin but it cannot be modified without code development.

Options in the Configure 8 plugin change colors, fonts, layout, features, etc.

I also created many Bludit plugins that are recognized by the Configure 8 theme but can be used with other themes. However, some of these plugins are made better by my theme and a couple require minor coding to get the most from them.
