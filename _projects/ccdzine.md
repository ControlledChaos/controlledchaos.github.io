I am including this website in my projects portfolio because it took a lot of learning, a lot of work, and I am proud of it. The design is hardly groundbreaking or impressive but it's something I got into my head a long time ago. So after operating many years without my own website, I have finally built it.

This website was built using only a free code editor on a Windows laptop and it is hosted on a free GitHub account. The only investment, other than my time, is the rental fee for the ccdzine.com domain.

## A Complete Departure

I typically build websites using the [WordPress](https://wordpress.org) or [ClassicPress](https://classicpress.net) content managements systems. I use WordPress because it is free, there are countless plugins available to extend its functionality, and it is what I know. The first websites that I built for others were assigned to me with the WordPress requirement and after all these years I am very comfortable with it.

To challenge myself I started looking at other options, those of which I had been aware and those that were new discoveries. GitHub is a service that I have used for a long time to store code files and for its "version control". However, I was only vaguely aware of its website hosting service and its capabilities to compile code files into a functional website.

So after a bit of research I created [a repository](https://github.com/ControlledChaos/controlledchaos.github.io) for this website's code and got to work.

## GitHub Pages

GitHub Pages is the name of GitHub's website hosting and building service that does not use databases per se. When setting it up for my website I was fully prepared to exercise old-fashioned website fundamentals. Then I saw that the "deployment" option for website files can be set to use their built-in platform.

Using this platform means knowledge of the [Jekyll](https://jekyllrb.com/) static site generator and the [Liquid](https://shopify.github.io/liquid/) template engine.

Liquid is used by Shopify for its online store service. I had once fumbled my way through making minor changes to a Shopify website while working as a subcontractor. But 13 years later I remembered nothing about it. Jekyll was completely new to me.

## Controlled Chaos Design

I came up with the Controlled Chaos name in 1984 for my landscaping and garden design services. The name lingered in my background during subsequent occupations then I put it back into service when I learned web design.

In contemplating a design for my own website, circa 2013, I decided to use the yin-yang symbol as a non-logo, thinking it clearly represents the dichotomy of control and chaos. So I began an Asian-flavored look.

The green comes from bamboo and for the life of me I can't recall form where the desaturated violet came. But they work together.

Fonts used are Crimson Pro for the serif display font and the sans-serif text is a mix of the Red Hat family.
